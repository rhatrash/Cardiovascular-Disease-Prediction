# Cardiovascular Disease Prediction — Project Solution

## 1. Objective

The objective is to preprocess the cardiovascular disease dataset, perform exploratory data analysis and visualization, inspect feature correlations, compare five machine-learning classifiers, and save the best-performing heart-disease detection model.

## 2. Dataset and preprocessing

The source file is the standard `cardio_train.csv` dataset containing 70,000 patient records. The target variable is `cardio`, where `0` indicates no cardiovascular disease and `1` indicates disease. The identifier column `id` was excluded from modeling because it is not a clinical predictor.

The following preprocessing operations were applied:

1. The semicolon-delimited dataset was loaded.
2. Age was converted from days to years using `age / 365.25`.
3. Duplicate rows were removed.
4. Clinically implausible observations were removed using the following conservative ranges: height 120–220 cm, weight 30–250 kg, systolic blood pressure 60–250 mmHg, diastolic blood pressure 40–200 mmHg, and systolic pressure greater than or equal to diastolic pressure.
5. Body-mass index was derived as `weight / height²`, with height converted to metres.
6. Median imputation was included in every modeling pipeline. Scaling was applied to SVM, KNN, and Logistic Regression; tree-based models were not scaled.
7. The cleaned dataset contained **68,618 rows**. No missing values were present in the original data.

## 3. Exploratory analysis and visualizations

The project package includes the following plots:

- Target-class distribution.
- Numeric distributions of age, height, weight, blood pressure, and BMI by outcome.
- Disease rates for gender, cholesterol, glucose, smoking, alcohol consumption, and physical activity.
- Boxplots of continuous predictors by disease outcome.
- Correlation heatmap.
- Pairwise relationships for a reproducible sample of patients.
- Model performance comparison.
- ROC curves and feature importance, where generated by the final run.

The target classes are reasonably balanced, so accuracy is suitable as a primary comparison measure, but precision, recall, F1, and ROC-AUC are also reported.

## 4. Correlation analysis

The strongest Pearson correlations with the disease target were:

| Feature | Correlation with `cardio` |
|---|---:|
| Systolic blood pressure (`ap_hi`) | 0.428 |
| Diastolic blood pressure (`ap_lo`) | 0.340 |
| Age in years | 0.239 |
| Cholesterol | 0.221 |
| BMI | 0.190 |
| Weight | 0.180 |
| Glucose | 0.090 |
| Physical activity | -0.038 |

These are associations, not causal effects. Blood-pressure measurements were the most strongly associated predictors in this dataset, followed by age, cholesterol, and BMI.

## 5. Model comparison

The classifiers were trained using a stratified 80/20 split of a reproducible 12,000-row modeling sample. The full cleaned dataset was used for preprocessing and exploratory analysis. The modeling sample was used to keep the nonlinear SVM benchmark computationally practical while preserving class balance.

| Model | Test accuracy | Precision | Recall | F1 | ROC-AUC |
|---|---:|---:|---:|---:|---:|
| **Random Forest** | **0.7396** | 0.7626 | 0.6958 | 0.7277 | **0.8045** |
| Logistic Regression | 0.7383 | **0.7653** | 0.6875 | 0.7243 | 0.8022 |
| SVM | 0.7367 | 0.7610 | 0.6900 | 0.7238 | 0.7976 |
| KNN | 0.7267 | 0.7459 | 0.6875 | 0.7155 | 0.7860 |
| Decision Tree | 0.7146 | 0.7493 | 0.6450 | 0.6932 | 0.7779 |

## 6. Selected model

The **Random Forest** model was selected because it achieved the highest test accuracy and ROC-AUC among the evaluated models. The saved detector includes the fitted preprocessing/model pipeline and the exact feature order:

`age_years, gender, height, weight, ap_hi, ap_lo, cholesterol, gluc, smoke, alco, active, bmi`

This model is intended for educational analysis only. It must not be used as a clinical diagnostic system without external validation, calibration, clinical review, bias assessment, and regulatory approval.

## 7. How to use the saved detector

```python
import joblib
import pandas as pd

bundle = joblib.load('outputs/cardiovascular_disease_detector.joblib')
model = bundle['model']
features = bundle['features']

new_patient = pd.DataFrame([{
    'age_years': 55,
    'gender': 1,
    'height': 170,
    'weight': 80,
    'ap_hi': 140,
    'ap_lo': 90,
    'cholesterol': 2,
    'gluc': 1,
    'smoke': 0,
    'alco': 0,
    'active': 1,
    'bmi': 80 / (1.70 ** 2)
}])[features]

prediction = model.predict(new_patient)[0]
probability = model.predict_proba(new_patient)[0, 1]
print('Predicted class:', prediction)
print('Estimated disease probability:', probability)
```
